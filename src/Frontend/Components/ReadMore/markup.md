# Readme button from codyhouse

## Installation

1. Ensure the component files are in the correct directory:
   ```
   src/Frontend/Components/Readme/readme.css
   ```

2. Import the CSS in your main styles.css file:
   ```css
   @import './Components/Readme/readme.css' layer(components);
   ```
