# Scroll based, modular frontend prototype


## Project Structure

```
/
├── images/                 # Image assets
├── src/
│   └── Frontend/
│       ├── Components/     # Reusable UI components
│       ├── StyleSheets/    # Base styles and typography
│       ├── main.js         # JavaScript entry point
│       └── styles.css      # CSS entry point
├── about.html              # About page
├── contact.html            # Contact page
├── index.html              # Homepage
└── README.md               # This file
```

## Component System

The project uses a component-based approach with:

- Modular, reusable UI components
- CSS using vanilla or Tailwind's @apply directives
- Minimal JavaScript where necessary
- Documentation for each component


## Getting Started

1. Clone the repository
2. `npm install`
3. `npm run dev` and open link shown in the terminal
